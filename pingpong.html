Multi-Camera Calibration and Ball Tracking for Ping-Pong Robotics

2025
  • ROS2 System Architecture
  • Computer Vision with YOLOv8 and OpenCV
  • Automated Multi-Camera Calibration
  • 3D Reconstruction
  • Multi-Camera Synchronization

Context / Problem 🔍:
Real-time ping pong-playing robots face challenges in integrating vision, control, and robotics to respond accurately to a fast-moving ball.

My Role 🛠️:
Developed and streamlined the full vision pipeline: performed multi-camera calibration, implemented YOLOv8-based ball detection and 3D triangulation, and contributed to ROS-based communication between vision and control systems.

Solution Summary 💡:
Built a real-time ping pong system that detects the ball using four overhead cameras, triangulates 3D position, predicts trajectory, and commands a robot arm to intercept or return the ball via reinforcement learning-based pose tracking.

Technical Highlights 🔧:

  • Automated checkerboard calibration for 4-camera setup, with stereo reprojection error analysis.
  • Used YOLOv8 with public dataset (Roboflow) for accurate ball detection.
  • Triangulated ball location using synchronized camera feeds, projection matrices, and camera intrinsic and extrinsic properties.
  • Built ROS2-ROS1 bridge for real-time communication between vision system and robotic controller.

Results / Key Outcomes 🏁:

  • Achieved successful 3D reconstruction from four overhead cameras through precise calibration and triangulation.
  • Enabled accurate real-time 3D tracking of a ping pong ball rolling across the table surface.
