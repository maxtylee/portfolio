Self-Driving Car with Battery Detection and Google Maps Navigation

2024
  • Embedded Systems & Sensor Integration
  • Autonomous Navigation Development
  • Python & System Integration
  • Control & Path Following
  • Rapid Prototyping & Hardware Design

Context / Problem 🔍:
In traditional vehicles, the driver can monitor battery levels and decide when to recharge. But in a self-driving car, there is no driver to check the battery level. Our Robo-Cybertruck project addressed this challenge by detecting low battery voltage and autonomously navigating to a designated “charging station” using GPS and Google Maps API.

My Role 🛠️:
Integrated hardware and software for autonomous navigation, including Arduino-based voltage sensing, Jetson Nano processing, and GPS localization. Developed Python scripts to connect battery monitoring with DonkeyCar navigation, implemented Google Maps API for route generation, and tested path-following accuracy through iterative PID tuning.

Solution Summary 💡:
Built a resin-printed Cybertruck-themed autonomous vehicle capable of monitoring its own battery levels, detecting low voltage, and navigating to a predefined charging station. The system combined real-time sensor feedback, Google Maps API path planning, and DonkeyCar control for end-to-end autonomy.

Technical Highlights 🔧:

  • Implemented Arduino Nano + voltage divider circuit for continuous battery health monitoring with LCD and buzzer feedback.
  • Integrated GPS navigation and converted latitude/longitude to UTM coordinates for precise motion tracking.
  • Used Google Maps API for automatic route generation to the charging station based on current location.
  • Applied PID control tuning and hardware mounting to improve navigation and perception accuracy.

Results / Key Outcomes 🏁:

  • Autonomously navigated to a charging station with ±1.5 m accuracy once low voltage was detected.
  • Validated end-to-end integration of voltage sensing, GPS navigation, and DonkeyCar control through real-world testing.
  • Delivered a functional system combining hardware prototyping, embedded programming, and software integration.
